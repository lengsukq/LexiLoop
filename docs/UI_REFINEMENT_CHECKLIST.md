## 彩色层级调整（2026-10-17）

根据后续反馈，将默认浅色从灰白松绿调整为清透蓝底与鲜绿主色，并为主要内容区域增加薄荷绿、浅蓝、淡紫、杏色分区。首页、词条详情、复习题目、添加、CSV、文章、内容补全、设置、统计和训练入口均使用共享配色；单词本的搜索区域与朗读操作获得强调。功能和布局取舍保持不变。

深色模式为对应的深色分区；选中状态保留描边和勾选，不依赖底色。截图图库使用本次颜色重新生成，先前 macOS 实机记录对应上一版布局与颜色；本次原生配色尚未重复实际运行验收。

本次追加验证：明暗彩色分区全部文字及标题图标对比度 ≥4.5:1；全量 2,132 项通过，3 项真实环境测试跳过；静态分析、格式与架构检查通过；macOS 调试构建通过。13 类页面与关键交互截图已更新。图库通过 `python3 tool/build_ui_review.py` 从本地截图重新生成。

## 答题流程重做（2026-10-17 晚）

针对「回答正确 / 自评：忘了」并排出现的截图与答题体验反馈，学习页按 Next 版
改成两段式：

- **作答 → 揭示 → 自评 → 自动下一题**。单题判定卡与「下一题」按钮删除；
  「自评：X」「掌握度」「下次复习」不再出现在单题界面。判定只出现一次，
  且发生在自评之前——客观对错与主观熟悉度不再被摆成一对矛盾。
- 客观判定与服务层共用 `previewAnswer`（`answer_evaluator.dart`）：界面说
  「回答正确」而库里记 `isCorrect=false` 这类漂移不可能再出现。
- 版面改为 `PageShell` 吸底动作条：未揭示时「稍后再学 / 忘记 / 检查答案」
  固定在底部；揭示后换成四档自评（≥600 宽一行四档，窄屏 2×2）。「跳过」从
  页头移到底部，页头只留「结束」。
- 键盘分阶段：作答时 `1–4` 选选项、`Space/Enter` 检查答案；揭示后 `1–4`/
  `Space` 才是自评；输入框聚焦时字母、空格、数字全部让位给输入法。
- 活跃计时在揭示时停表：挑自评档位的思考时间不再计入作答时长。
- 设置页的「揭示延迟」与「自动朗读」真正生效。自动朗读只在听到发音不会
  泄露答案的题型播放（拼写/填空/看义选词不播），且不再弹降级提示。
- 揭示面板包含判定、词条、音标、释义、错答差异与例句折叠；不包含 AI 助记 /
  词根词缀（`StudyWordView` 未携带，见 `FLUTTER_PARITY.md` 已知差异）。
